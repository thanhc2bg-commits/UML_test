Mục tiêu bài học

  • Hiểu quan hệ «include»: hành vi của Included use case được tích hợp vào Base use case.
  • Phân biệt Base use case và Included use case, và biết chiều mũi tên «include».
  • Nhận biết ví dụ đúng (Announce course, Assign lecturer) và ví dụ bị đánh dấu sai (Gumball Machine).

1. Quan hệ «include» Slide 10

Hành vi của Use case được sử dụng (Included use case) được tích hợp vào Use case sử dụng (Base use case). Trong sơ đồ, quan hệ là mũi tên nét đứt có nhãn «include», đi từ A (Base use case) tới B (Included use case).

Bấm nút để xem A và B hoạt động ra sao, hoặc chạm trực tiếp vào A, B và mũi tên.

Use case đang được thực thi   Hành vi được tích hợp vào Base use case

Base use case (A)yêu cầu B để đảm bảo chức năng.
Included use case (B)B cũng có thể được thực thi riêng biệt.

2. Ví dụ: Announce course «include» Assign lecturer

Trong hệ thống Student Administration, Professor nối với cả hai Use case. Announce course là Base use case, Assign lecturer là Included use case.

3. Ví dụ bị đánh dấu sai: Gumball Machine

Slide gạch chéo ví dụ này: Buy chewing gum «include» Insert coin, với Person nối vào cả hai. Thử chạy để đối chiếu với ví dụ đúng ở trên.

So sánh hai ví dụ: cả hai có cùng cấu trúc (Actor nối với cả Base và Included, mũi tên «include» đi từ Base sang Included), nhưng chỉ ví dụ Announce course / Assign lecturer được dùng làm ví dụ đúng, còn Gumball Machine bị gạch chéo.

Ghi nhớ nhanh

  • Hành vi của Included use case được tích hợp vào Base use case.
  • Ký hiệu: mũi tên nét đứt có nhãn «include», đi từ Base (A) tới Included (B).
  • Base use case yêu cầu B để đảm bảo chức năng; Included use case cũng có thể được thực thi riêng biệt.
  • Ví dụ đúng: Announce course «include» Assign lecturer. Ví dụ bị gạch chéo: Buy chewing gum «include» Insert coin.
